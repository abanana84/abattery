# Changelog

All notable changes to ABattery are documented here.

## [1.1.5] - Unreleased

- Updated the app to target Android 16 (API 36) for Google Play compliance.
- Updated the Android build toolchain while keeping Android 8.0 device support.

## [1.1.4] - 2026-04-16

- Fixed a cold-start crash.
- Improved release configuration and resource hygiene.

## [1.1.1] - 2026-04-16

- Fixed locale and resource handling.
- Prepared the app for a stable Play Store release.

## [1.0.0] - 2026-04-15

- Added the battery health dashboard, current chart, capacity details, and cycle count.
- Added light, dark, and system themes.
- Added 16-language support and launcher assets.
