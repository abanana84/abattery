# Support

- Ask usage questions in [GitHub Discussions](https://github.com/abanana84/abattery/discussions).
- Report reproducible bugs with the [bug report form](https://github.com/abanana84/abattery/issues/new?template=bug.yml).
- Request improvements with the [feature request form](https://github.com/abanana84/abattery/issues/new?template=feature.yml).
- Download the published app from [Google Play](https://play.google.com/store/apps/details?id=com.abanana.abattery).

Battery data availability depends on the Android version and device manufacturer. Include the device model, Android version, and app version when requesting help.
