# Security Policy

## Supported versions

Security fixes are provided for the latest released version of ABattery.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting feature from the repository's **Security** tab. Include a clear description, affected version, reproduction steps, and potential impact. Reports will be acknowledged as soon as practical.

Private Code of Conduct reports may use the same channel with `[Conduct]` at the start of the title.

Only test devices, accounts, and systems that you own or are authorized to assess.
